# Online Book Store - Web Designing Workshop (BCS-353)

A static web application developed as part of the Web Designing Workshop (BCS-353) Lab Manual for GL Bajaj Institute of Technology & Management (GLBITM).

## Features
- **Frameset Layout (`home.html` / `frames.html`)**: Classic 3-frame architecture (Header, Navigation sidebar, Main content area).
- **Header (`top.html`)**: Dynamic marquee header, institute emblems, and top-level navigation.
- **Department Sections (`left.html`)**:
  - `cse.html` (Computer Science and Engineering)
  - `ece.html` (Electronics and Communication Engineering)
  - `eee.html` (Electrical and Electronics Engineering)
  - `mech.html` (Mechanical Engineering)
- **Interactive Catalogue (`catalogue.html`)**: Book listing with covers, publication details, pricing, and dynamic cart integration.
- **Dynamic Shopping Cart (`cart.html`)**: 
  - Dynamic local-storage backed shopping cart
  - Book covers, live quantity counter, and real-time total calculation
  - Clear cart & item removal features
- **User Authentication (`login.html`)**: Login portal with ID & password authentication fields.
- **Registration & Validation (`registration.html` / `validation.html`)**:
  - Form validations with client-side JavaScript regex
  - Minimum 3 letters, alphabetic first name validation
  - Strict Gmail address verification (`@gmail.com`)
  - 10-digit numeric phone number validation
- **CSS Explorations (`sample.html` & `style.css`)**: Demonstrations of internal, inline, and external styling, background controls, and cursor states.
- **Survey Form (`survey.html`)**: Responsive questionnaire form.

## How to Run
Simply open `home.html` or `index.html` in any web browser.
